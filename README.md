# Stanslous Nhau UX Portfolio — GitHub Pages

This folder is ready to publish as a static website on GitHub Pages.

## 1. Update your contact details before publishing

Open `index.html` and replace:

- `YOUR_EMAIL_HERE`
- `YOUR_LINKEDIN_URL_HERE`

You can search for those exact strings.

## 2. Create a GitHub repository

1. Go to GitHub.
2. Click **New repository**.
3. Name it something like `ux-portfolio`.
4. Make it **Public**.
5. Create the repository.

## 3. Upload these files

Upload the **contents of this folder**, not the zip itself:

- `index.html`
- `fuse.html`
- `rise.html`
- `velocity.html`
- `styles.css`
- `script.js`
- the entire `assets` folder

Commit the changes.

## 4. Turn on GitHub Pages

1. In the repository, go to **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
4. Click **Save**.

After a minute or two, GitHub will show your live URL, usually:

`https://YOUR-GITHUB-USERNAME.github.io/ux-portfolio/`

## 5. Optional: use your own domain

You can later connect a domain such as `stanslousnhau.com` from the GitHub Pages settings.

## What is included

- Responsive homepage

The RISE and Velocity case studies deliberately describe their validation limits instead of inventing usability-test results. Add real testing evidence later once you run usability sessions.
